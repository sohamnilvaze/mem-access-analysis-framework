*** Comparison with some other similar looking research*** 

| Work                                                     | Methodology                           | Objective                                                     | Feature Representation               | Interpretability | Limitations                                                           |
| -------------------------------------------------------- | ------------------------------------- | ------------------------------------------------------------- | ------------------------------------ | ---------------- | --------------------------------------------------------------------- |
| Learning Memory Access Patterns                          | Deep Learning (RNN/LSTM)              | Predict next memory access for hardware prefetching           | Raw memory address sequences         | ❌ None           | Black-box model, difficult to interpret memory behavior               |
| ACORN: Accurate Open‑set Recognition for Memory Workload | ML-based workload recognition         | Identify memory workload classes and detect unknown workloads | Spatial locality + sequence features | ❌ Limited        | Focuses on workload recognition rather than pattern-level explanation |
| Memory Reference Behavior Characterization Studies       | Statistical analysis                  | Understand memory reference behavior of applications          | Statistical metrics                  | ⚠ Partial        | No predictive classification model                                    |
| Pattern-Aware Memory System Research                     | Architecture-driven pattern detection | Improve memory system performance                             | Hardware-centric metrics             | ❌ None           | Not focused on ML-based analysis                                      |
| **Proposed Framework (This Work)**                       | Decision Tree + SHAP                  | Interpretable classification of memory access patterns        | Trace-driven statistical features    | ✅ High           | Currently assumes closed-set classes                                  |
